1. Judul Program

Program Percakapan Dua Teman Menggunakan Python

2. Deskripsi Program

Program ini merupakan contoh penerapan konsep Pemrograman Berorientasi Objek (PBO) menggunakan bahasa Python. Program menggambarkan percakapan antara dua orang teman bernama Teuku dan Iyung yang sedang berbincang di sebuah kafe.

Dalam program ini terdapat sebuah class bernama "Teman" yang memiliki atribut nama dan hobi serta beberapa method untuk melakukan percakapan, seperti menyapa, menanyakan kabar, menceritakan hobi, mengajak nongkrong, dan berpamitan.

3. Tujuan Program

1. Memahami konsep dasar Pemrograman Berorientasi Objek.
2. Memahami penggunaan class dan object dalam Python.
3. Memahami penggunaan atribut dan method.
4. Mempelajari penggunaan constructor "__init__".
5. Memahami penggunaan kondisi "if" dalam sebuah method.
6. Membuat program percakapan sederhana menggunakan Python.

4. Konsep PBO yang Digunakan

A. Class

Class adalah cetakan atau rancangan untuk membuat objek. Dalam program ini menggunakan class "Teman".

B. Object

Object adalah hasil pembuatan dari sebuah class. Program ini membuat dua objek, yaitu "teman1" dan "teman2".

C. Atribut

Atribut merupakan data yang dimiliki oleh objek. Pada program ini terdapat atribut:

- "nama"
- "hobi"

D. Constructor

Constructor "__init__" digunakan untuk memberikan nilai awal pada objek ketika objek dibuat.

E. Method

Method merupakan fungsi yang berada di dalam class. Method yang digunakan dalam program ini adalah:

- "sapa()"
- "tanya_kabar()"
- "jawab_kabar()"
- "cerita_hobi()"
- "ajak_nongkrong()"
- "tanggapi_ajaran()"
- "pamitan()"

F. Percabangan

Program menggunakan kondisi "if" pada method "tanggapi_ajaran()" untuk menentukan respons berdasarkan nilai parameter "setuju".

5. Penjelasan Alur Program

1. Membuat class "Teman".
2. Menentukan atribut nama dan hobi.
3. Membuat beberapa method percakapan.
4. Membuat dua objek, yaitu Teuku dan Iyung.
5. Menjalankan percakapan secara berurutan.
6. Program menampilkan percakapan hingga kedua teman berpamitan.

6. Kesimpulan

Dari program ini dapat disimpulkan bahwa Pemrograman Berorientasi Objek dapat digunakan untuk membuat program yang lebih terstruktur dan mudah dipahami.

Dengan menggunakan class, object, atribut, constructor, dan method, kita dapat membuat simulasi percakapan sederhana antara dua orang teman.
